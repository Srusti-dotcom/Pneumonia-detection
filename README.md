# PneumoVision AI – Pneumonia Detection Using Chest X-rays

## About
PneumoVision AI is a deep learning project that classifies chest X-ray images into **NORMAL** and **PNEUMONIA** categories using CNN and transfer learning models.

## Models Used
- Custom CNN
- MobileNetV2
- DenseNet121
- VGG16

## Features
- Chest X-ray image preprocessing
- Data augmentation
- Model training and fine-tuning
- Performance comparison
- Accuracy, Precision, Recall and F1-score
- Confusion matrices and ROC curves
- Prediction on uploaded X-ray images

## Dataset
[Kaggle – Chest X-Ray Images (Pneumonia)](https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia)

## Technologies Used
- Python
- TensorFlow / Keras
- NumPy and Pandas
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab
- Streamlit (optional interface)

## How to Run
1. Clone this repository.
2. Open `PneumoVision_AI_Corrected.ipynb` in Google Colab.
3. Configure Kaggle API credentials.
4. Download and load the dataset.
5. Run the notebook cells in order.
6. Train the models and evaluate their performance.

## Objective
To explore and compare CNN and transfer learning techniques for classifying pneumonia-related patterns in chest X-ray images.

## Disclaimer
This project is developed for educational purposes only. It is not intended for clinical diagnosis or medical decision-making.
